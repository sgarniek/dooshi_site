# 🍪 Dooshi — מדריך מפתח

## מבנה הפרויקט

```
dooshi/
├── index.html        ← דף ה-HTML הראשי (מבנה האתר)
├── css/
│   └── style.css     ← כל העיצוב (צבעים, פריסה, אנימציות)
├── js/
│   └── app.js        ← כל הלוגיקה (מוצרים, עגלה, הזמנות, ניהול)
└── README.md         ← המסמך הזה
```

---

## פתיחה בדפדפן (ללא שרת)

1. פתחו את תיקיית `dooshi` ב-VS Code
2. התקינו את התוסף **Live Server** (מחפש ב-Extensions: `ritwickdey.liveserver`)
3. לחצו קליק ימני על `index.html` → "Open with Live Server"
4. האתר ייפתח בדפדפן בכתובת `http://127.0.0.1:5500`

חלופה ללא Live Server: לחצו פעמיים על `index.html` — ייפתח ישירות בדפדפן.

## כניסה ללוח ניהול

- לחצו על כפתור "ניהול" בניווט העליון
- סיסמה ברירת מחדל: dooshi123
- לשינוי הסיסמה: פתחו js/app.js → שורה 1 → שנו את adminPassword

## הוספת מוצרים

העתיקו בלוק קיים, שנו את כל השדות, ותנו id ייחודי.

## שינוי צבעים
